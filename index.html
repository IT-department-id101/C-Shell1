Implicit & Explicit Casting – گۆڕینی خۆکار و دەستیی جۆری داتا
PDF P.14
123456789
int myInt = 9;
double myDouble = myInt; // گۆڕینی خۆکار: int بۆ double
Console.WriteLine(myInt);
Console.WriteLine(myDouble);

double myDouble2 = 9.78;
int myInt2 = (int) myDouble2; // گۆڕینی دەستیی: double بۆ int
Console.WriteLine(myDouble2); // دەرەنجام: 9.78
Console.WriteLine(myInt2); // دەرەنجام: 9
:دەرەنجام  |  Output:
9 9 9.78 9
📚 ڕوونکردنەوەی تەواو:
  • ١int myInt = 9; : گۆڕاوی جۆری int بە نرخی 9
  • ٢double myDouble = myInt; : Implicit Casting — گۆڕینی خۆکار لە جۆری بچووک (int) بۆ جۆری گەورە (double)، پێویست بە هیچ نووسینێکی زیاتر نییە
  • ٣Console.WriteLine(myInt); : نرخی myInt چاپدەکرێت — 9
  • ٤Console.WriteLine(myDouble); : نرخی myDouble چاپدەکرێت — 9 (وەک double نیشان دەدرێت)
  • ٦double myDouble2 = 9.78; : گۆڕاوێکی نوێی جۆری double بە نرخی 9.78
  • ٧int myInt2 = (int) myDouble2; : Explicit Casting — گۆڕینی دەستیی لە جۆری گەورە (double) بۆ جۆری بچووک (int)، جۆرەکە لەناو () دادەنرێت
  • ٨Console.WriteLine(myDouble2); : نرخی سەرەتایی چاپدەکرێت — 9.78، هیچی نەگۆڕاوە
  • ٩Console.WriteLine(myInt2); : کاتێک double بۆ int دەگۆڕدرێت، بەشی دوای خاڵی دەبڕدرێت — دەرەنجام دەبێتە 9 نەک 9.78
  • 💡ڕیزبەندی جۆرەکان : char → int → long → float → double
